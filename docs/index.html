    What Lean proves

    Every nontrivial zero of the Riemann zeta function lies on the critical line. Main.lean exports this result with Mathlib’s RiemannHypothesis type, alongside the corresponding results for Dirichlet L-functions.

    ζ(s) = 0, s ∉ {−2, −4, …}, s ≠ 1 ⟹ Re(s) = ½

    Embedded terms

    The corpus is the original Lean release preserved by the Lean community. Identifiers within each source line supply the contexts for a continuous bag-of-words model with negative sampling. Imports are indexed for navigation and omitted from model training.

    Nearest terms are ranked by cosine similarity in 64 dimensions. The embedding atlas groups the normalized vectors into eight regions, then clusters each region again. The labels summarize inspected examples. Each subcluster uses its own two-dimensional PCA projection. Full PCA uses one projection for all regions. Hover or focus a region in the legend to isolate its plotted members. Similarity measures shared textual context. File links point to source occurrences.

    The Lean reader uses the published compilation metadata to link explicit references in declarations. Kernel refs reads the constants in the compiled type and proof term. The Used by panel searches modules with metadata indexed locally. Mathlib references open the pinned source.
